# AIVORA Studio v2.0.0 发布说明（集成候选版 — 经双平台实机与发布授权后方可公开）

> **发布诚实声明**：本清单仅列出**已完整接通前端界面 / IPC / 主进程且通过回归与真机冒烟**的用户可见功能。尚未开放独立界面入口的底层契约模块单独列在文末「底层契约已就绪（v2.1 逐步开放界面）」中；未经真实付费账号实测的供应商能力保持默认关闭；精剪素材包采用标准开放格式（视频素材 + 4 路 48kHz WAV 分轨 + SRT + 有理帧率 EDL/JSON），不宣称生成 Premiere / DaVinci / Final Cut 原生工程文件。

## 本版已接通的核心功能

### 1. 数据安全、先备份后迁移与事务一致性（DB1 / DB2 / F01–F05）
- **SQLite 忙锁事务安全、嵌套 `SAVEPOINT` 与独占文件暂存**：`BEGIN IMMEDIATE` 锁争用不污染事务状态位，嵌套事务采用 `SAVEPOINT` 独立回滚；事务失败仅清理本次独占新建文件。
- **严格「先备份后迁移」**：启动扫描工作区只读识别工程，不触发静默迁移；打开旧工程执行任何建表/改表 DDL 前，先通过 `VACUUM INTO` + `PRAGMA integrity_check` 生成滚动验证备份（保留 3 份）。
- **剧本拆镜闸门与锚点一对一匹配（F01 / F02）**：采纳提案前强制核验剧本与依赖 SHA-256，防止旧提案/并发双击覆写；重拆镜按稳定 ID 或唯一源锚点一对一匹配，移除镜头进入 `archived_takes` 可撤销归档。
- **严谨垫图注入与候选只读保护（F03 / F04）**：去除全局兜底与台词捞图，缺必需锁定参考拦截并跳资产卡；禁止 `/images/edits` 404/405/501 静默退化；所有生成与外采回片仅写候选，绝不冲掉既有定稿。
- **流式排他发布、发布前双质检与崩溃恢复日志（F05 / F14 / A03 / A04）**：
  - 成片发布改用分块流式写入 + 硬链接排他发布（消除 2GB Buffer 限制）；
  - 试片轻量直出；**正式交付**先对暂存文件完成确定性内容/字幕质检与技术质检（拦截黑屏、缺失轨与响度超限），达标后再排他发布到最终路径，并通过 SQLite 交付日志支持发布后异常退出的重启核验恢复；
  - 剪辑变更后旧报告立即标记「上次导出（已过期）」。

### 2. 统一预算账本、前期门禁与参数预检（F16 / M01–M04 / F08–F10）
- **全付费入口统一预算账本与诚实结算**：生图、视频、配音与 Lyria AI 配乐均收口至原子 `BEGIN IMMEDIATE` 预算账本 + `jobs` 单事务落盘；视频估价区分模型与分辨率；上游未返回实付金额时标为「按预估暂结（`settled_estimated`）」而不伪造实付；发包后网络中断或本地保存失败一律落 `UNKNOWN` / `unknown_hold` 防重复扣费，启动对账同步更新任务与台账。
- **前期门禁与场记连戏实时注入**：在真实生成入口（`plan-builder`）接入场次协调器、场记连戏链（区分身体物理左右与银幕左右、前镜动作末态承接、仅画内说话人触发口型提示）以及 M01–M04 官方参数预检（不合法时长/互斥角色零请求拦截）。

### 3. 音视频引擎与 Editroom 精剪增强（F11 / F12）
- **随包 SIL OFL 1.1 中文字体**（`resources/fonts/NotoSansCJK-Regular.ttc`）。
- **单镜内容哈希缓存 + 局部零漂移转场**：`dip_to_black` 采用原地淡出淡入（零时长缩短、零音画偏移，且质检自动豁免黑屏误报），`dissolve` 视音频锁定相同叠化时长；支持 `native_audio` / `silent_tts` / `env_plus_tts` 三路声音合同。
- **对白区间限定波形闪避与 `-16±1 LUFS / ≤-1.0 dBTP` 有界重修**：仅在有对白镜头内按 `silencedetect` 真实人声窗平滑闪避 BGM，避免无对白原声空镜误压配乐；超限通过 `-c:v copy` 纯音轨有界重修。
- **带时间戳 ContactSheet 帧网格**：烧录精确时间角标并按内容哈希缓存，可在第五页交付预览直接生成抽查。

### 4. 外采强溯源防篡改与第五页「交付」（F13 / F18 / 多集续跑）
- **外采回流 TOCTOU 防替换与清单溯源（F13）**：扫描读取 `pack-manifest.json`，重排或跨项目文件强制进入人工核对；提交强制校验扫描期 `expectedSha256`，经项目私有暂存拷贝验签后再探测与入库，阻断确认后原路径被替换为其他文件的漏洞。
- **第五页「交付」（≥2 集按需开放）**：
  - 主按钮直接驱动 SQLite 持久化多集导出、断点续跑（失败重启后已校验通过分集零重渲）与按序合片；
  - 侧栏提供真实可点击的 **F14 内容/字幕质检复查** 与 **F18 标准精剪素材包导出**（可重连素材 + 4 路 48kHz WAV 分轨 + SRT + 有理帧率 EDL/JSON + `CHECKSUMS.sha256` + 零凭据校验）。
