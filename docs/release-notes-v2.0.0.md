# AIVORA Studio v2.0.0 发布说明（集成候选版 — 待双平台 CI 绿灯、候选包真机实测与发布授权后方可公开）

> **发布诚实声明**：本清单仅列出**已完整接通前端界面 / IPC / 主进程并通过自动化回归与 Linux 无头 Electron 验收**的 6+1 项核心能力（Windows 真机升级与最终候选包界面验收将在双平台 CI 绿灯后补齐记录）。未经真实目标环境实测的 8 项扩展能力（见文末清单）一律移出 v2.0.0 发布范围，不在本版对外宣称支持。

## 本版已接通的 6+1 项核心能力

### 1. 预算防护与诚实账本（`budget_policies` + 全付费入口收口）
- **作品预算上限放在现有设置中，发包前统一拦截**：在「模型中心」可为当前作品设置总预算上限，在「任务队列」随时查看实付确认、按预估暂结、待查单暂挂与剩余额度。
- **全付费入口统一收口**：导演拆镜（含逐场长剧本总预算前置核验）、动作精修、生图、视频、配音与 Lyria AI 配乐均经主进程单 `BEGIN IMMEDIATE` 原子预扣+账本落盘；视频估价区分模型与分辨率；上游未返回实际账单时如实标注「按预估暂结（`settled_estimated`）」，不冒充实际账单；发包后断网或本地写盘失败一律落 `UNKNOWN` / `unknown_hold` 防重复扣费。

### 2. 中断任务三态恢复（接进现有任务中心）
- 在「后台任务与中断恢复」抽屉中按三态安全处理中断任务：
  - **有远端任务号**：仅允许 GET 查单找回，绝不重复 POST 扣费；
  - **不确定是否已扣费（无远端任务号）**：冻结自动重发，仅允许人工核对服务商后台后粘贴任务号查单；
  - **确定未发出且原授权零漂移**：支持核验输入摘要后安全续跑（若参数已变更则自动释放旧预扣并要求重新确认）。

### 3. 请求前参数预检（`provider-preflight`）
- 接入已支持模型（Seedance / Kling / Gemini Omni）的真实请求前校验，以最终发送参数为准，不支持的时长、互斥角色或超限参考图提前中文拦截、零网络请求、绝不静默丢弃参考图；不顺带上线未验证新供应商。

### 4. 外采回流强溯源与防替换（`matchExternalDropWithProvenance` + TOCTOU 私有暂存）
- 扫描读取 `pack-manifest.json` 绑定项目、分集、镜头与版本摘要，重排或跨项目文件强制进入人工核对；
- 提交绑定扫描期 `expectedSha256`，经项目私有目录暂存拷贝单次验签后再探测与入库，同名换文件必须重新确认，且所有回片仅写候选、绝不覆盖既有定稿。

### 5. 原四页前期门禁、场记连戏与数据安全底座（DB1 / DB2 / F01–F05）
- **沿用原四页，零冗余菜单**：场次地点、在场人物、动作起止、身体物理左右与银幕左右、前镜动作末态与画外音零口型约束直接进入真实出图/生视频请求体；前期门禁在动态故事板未审或核心参考未锁定时拦截生视频。
- **数据安全与先备份后迁移**：SQLite 忙锁事务安全 + 嵌套 `SAVEPOINT`；启动扫描只读不触发 DDL；打开旧工程前强制 `VACUUM INTO` + 只读 `PRAGMA integrity_check` 生成滚动备份（3 份）；支持嵌套 `assets/` 目录递归归档备份、ZIP 炸弹流式限流与特殊路径（含单引号/冒号/空格/中文）FFmpeg 随包中文字体烧录。

### 6. 内容质检、技术质检、人工审片确认与崩溃安全正式交付（F05 / F14）
- 试片轻量直出；**正式交付（含剪辑页单集与第五页多集）**由主进程统一强制校验：须先完成当前快照版本的人工审片确认（剪辑页导出弹窗与第五页交付抽屉均提供确认入口，修改剪点/台词/素材后自动失效），并对暂存文件强制执行内容/字幕质检与技术质检（拦截黑屏、缺失轨、响度超限，无法通过界面传参跳过），达标后再经流式分块 + 硬链接排他发布到最终路径。
- 引入 SQLite 正式交付日志并在重开工程时自动按目标文件 SHA-256 对账恢复；只有同版本快照且双质检通过并完成发布的分集才显示「已正式交付」，修改剪点/台词/素材或中途退出立即失效。

### 7. 第五页「交付」（≥2 集按需开放，多集排序与断点续跑合片）
- 顶栏收敛无竞争导出按钮；≥2 集作品开放第五页「交付」，支持勾选分集、调整排片顺序、SQLite 持久化多集导出、第 3 集失败重启后仅补失败集（续跑仅复用同剪辑版本、同导出模式且具备合格质检与交付记录的成片，试片绝不被正式任务直接复用）并按用户顺序合片，以及当前集 F14 内容/字幕质检复查与审片确认。

## 以下 8 项已明确移出 v2.0.0 发布范围（保留底层代码供 v2.1 实测后开放）
为严守「未验证不宣称」原则，以下 8 项**不开放 2.0 入口、不纳入 2.0 功能承诺**：
1. **MiniMax / 海螺异步视频供应商**：待真实付费账号完成提交与查单实测后开放；
2. **标准精剪素材包（`finishing-pack`）**：待在至少一款目标剪辑器（Premiere / DaVinci / Final Cut）完成真实导入、修改、保存、重开闭环后再开放；
3. **帧缩略图接触表（ContactSheet）**：留待 v2.1 审片辅助视图开放；
4. **局部转场缓存卖点**：剪辑页既有转场的零音画漂移作为底层修复保留，不作为 v2.0.0 独立新特性宣称；
5. **同场宫格生成**（`creative-presets`）；
6. **角色三视图生成**（`creative-presets`）；
7. **双档升格生成**（`creative-presets`）；
8. **外部 `SKILL.md` 模板导入管理面板**（`skill-md-registry`）。
