# AIVORA Studio v2.0.0 发布说明

> **发布诚实声明**：本清单仅列出已完整接通前端界面 / IPC / 主进程并通过 Windows + Linux 双平台 CI（42 组单测 145 条用例、28 组多分辨率布局审计、Windows NSIS 安装/升级/卸载冒烟、Linux `.deb` 中文空格路径无头冒烟）与真实 Electron 10 阶段端到端实测的 6+1 项核心能力。未经真机实测或未纳入 2.0 边界的扩展能力（含 `feat/v2.1-video-continuity` 分支上的首尾帧/多模态参考视频/J-L Cut 音画错峰等）一律留待 v2.1 实测后开放。

## 本版已接通的 6+1 项核心能力

### 1. 预算防护与诚实账本（`budget_policies` + 全付费入口收口）
- **作品预算上限放在现有设置中，发包前统一拦截**：在「模型中心」可为当前作品设置总预算上限，在「任务队列」随时查看实付确认、按预估暂结、待查单暂挂与剩余额度。
- **全付费入口统一收口**：导演拆镜（含逐场长剧本总预算前置核验）、动作精修、生图、视频、配音与 Lyria AI 配乐均经主进程单 `BEGIN IMMEDIATE` 原子预扣+账本落盘；Gemini 文本请求强制携带 `generation_config.max_output_tokens`，返回后按模型单价与实测用量（含 `total_thought_tokens`）校对账本，缺失用量或发包后断网一律落 `UNKNOWN` / `unknown_hold`（待核对、不标零费用、不冒充实际账单、严防自动重发）。

### 2. 中断任务三态恢复（接进现有任务中心）
- 在「后台任务与中断恢复」抽屉中按三态安全处理中断任务：
  - **有远端任务号**：仅允许 GET 查单找回，绝不重复 POST 扣费；
  - **不确定是否已扣费（无远端任务号）**：冻结自动重发，仅允许人工核对服务商后台后粘贴任务号查单；
  - **确定未发出且原授权零漂移**：支持核验输入摘要后安全续跑（若参数已变更则自动释放旧预扣并要求重新确认）。

### 3. 请求前参数预检（`provider-preflight`）
- 接入已支持模型（Seedance / Kling / Gemini Omni）的真实请求前校验，以最终发送参数为准，不支持的时长、互斥角色或超限参考图提前中文拦截、零网络请求、绝不静默丢弃参考图；保存厂家配置失败时提供清晰的 Toast 与表单内联报错反馈。

### 4. 外采回流强溯源与防替换（`matchExternalDropWithProvenance` + TOCTOU 私有暂存）
- 扫描读取 `pack-manifest.json` 绑定项目、分集、镜头与版本摘要，重排或跨项目文件强制进入人工核对；
- 提交绑定扫描期 `expectedSha256`，经项目私有目录暂存拷贝单次验签后再探测与入库，同名换文件必须重新确认，且所有回片仅写候选、绝不覆盖既有定稿。

### 5. 原四页前期门禁、场记连戏、跨实例导出保护与数据安全底座
- **沿用原四页，零冗余菜单**：场次地点、在场人物、动作起止、身体物理左右与银幕左右、前镜动作末态与画外音零口型约束直接进入真实出图/生视频请求体；明确时空换场（非对白）自动分场；剪辑页清晰区分「可试片 / 正片缺配音」与说话人确认状态。
- **跨实例与数据安全**：导出临时目录写入归属 PID 元信息，启动清理绝不误删并发实例的活跃导出；SQLite 忙锁事务安全 + 嵌套 `SAVEPOINT`；打开旧工程前强制 `VACUUM INTO` + 只读 `PRAGMA integrity_check` 生成滚动备份（3 份）；支持递归归档备份（规避 Windows Node 22 中文路径 `cpSync` 崩溃）与特殊路径 FFmpeg 随包中文字体烧录。

### 6. 内容质检、技术质检、人工审片确认与崩溃安全正式交付（F05 / F14）
- 试片轻量直出；**正式交付（含剪辑页单集与第五页多集）**由主进程统一强制校验：须先完成当前快照版本的人工审片确认（修改剪点/台词/素材后自动失效），并对暂存文件强制执行内容/字幕质检与技术质检（拦截黑屏、缺失轨、响度超限，无法通过界面传参跳过），达标后再经流式分块 + 硬链接排他发布到最终路径。
- 引入 SQLite 正式交付日志并在导出后立即刷新界面、重开工程自动按 SHA-256 对账恢复；同快照技术质检仍有提醒与剪辑修改失效明确区分，绝不误报。

### 7. 第五页「交付」（≥2 集按需开放，多集排序与断点续跑合片）
- ≥2 集作品按需开放第五页「交付」，支持勾选分集、调整排片顺序（标题清晰标示 `排片 #N`）、SQLite 持久化多集导出、单集失败后仅补失败集（续跑仅复用同剪辑版本、同导出模式且具备合格质检与交付记录的成片，试片绝不被正式任务直接复用）并按用户顺序合片。

## 以下扩展能力已明确移出 v2.0.0 发布范围（留待 v2.1 实测后开放）
为严守「未验证不宣称」原则，以下内容**不纳入 v2.0.0 公开承诺**：
1. **MiniMax / 海螺异步视频供应商**；
2. **标准精剪素材包（`finishing-pack`）**；
3. **帧缩略图接触表（ContactSheet）**；
4. **首尾帧桥接 / 多模态参考视频 / 抽尾帧 / J-L Cut 音画错峰与转场扩展**（已完整保留在 `feat/v2.1-video-continuity` 分支）；
5. **同场宫格生成 / 角色三视图生成 / 双档升格生成**（`creative-presets`）；
6. **外部 `SKILL.md` 模板导入管理面板**（`skill-md-registry`）；
7. **空镜自动生成临时画板试片（F03）**。
