# AIVORA Studio v2.0.0 发布说明（草稿 — 经双平台实机与发布授权后方可公开）

> **发布诚实声明**：本版本仅对已完成自动化与本机/双平台实测的功能作出支持承诺。未经真实付费账号实测的供应商能力保持默认关闭，不对外宣称支持；精剪素材包采用标准开放格式（视频素材 + 4 路 48kHz WAV 分轨 + SRT + 有理帧率 EDL/JSON），不宣称生成 Premiere / DaVinci / Final Cut 原生工程文件。

## 核心更新

### 1. 数据安全与事务一致性（DB1 / DB2 / F01–F05）
- **SQLite 事务状态安全（DB1）与独占文件暂存（DB2）**：`BEGIN IMMEDIATE` 锁争用不污染事务状态位，事务回滚仅清理本次独占新建文件，绝不误删历史或并发共享资产。
- **备份先行迁移与滚动验证备份**：升级迁移前通过 `VACUUM INTO` + `PRAGMA integrity_check` 生成并校验滚动备份（保留 3 份），校验不通过绝不执行迁移。
- **剧本拆镜闸门与锚点一对一匹配（F01 / F02）**：采纳提案前强制核验剧本与依赖 SHA-256，防止旧提案/并发双击覆写；重拆镜仅按稳定 ID 或唯一源锚点一对一匹配，移除镜头进入 `archived_takes` 可撤销归档。
- **严谨垫图注入与候选只读保护（F03 / F04）**：移除全局兜底与台词子串捞图，缺失必需锁定参考时原地拦截并定位资产卡；禁止 `/images/edits` 404/405/501 静默退化为无图生图；所有回片仅写候选，绝不冲掉既有定稿视频或生图采用版本；拦截已退役模型。
- **排他原子成片发布与过期报告拦截（F05 / A03 / A04）**：采用目录内唯一暂存 + 硬链接排他发布，目标同名先引导另存，取消与已发布边界严格区分；剪辑素材/参数变更后旧质检报告立即标记「上次导出（已过期）」，不可继续作为正式交付依据；损坏 ZIP 导入原地说明中文原因并清理临时目录。

### 2. 前期可拍闭环与统一状态真相（F06–F10 / F15）
- **四维统一派生真相（`studio-truth.ts`）**：创作审批、远端任务、素材版本、交付资格均由 SQLite 与素材快照单一派生，剪辑与交付共用同一判定。
- **可拍剧本与因果分场（F06）**：支持原文/可拍稿对照、节奏预设、跨场因果重置（仅继承合理物件/伤势）与离线「整理草稿」。
- **三层版本化制作单与场记连戏（F07–F10 / F15）**：项目/集/场三层制作单与镜头七组结构化字段；明确区分角色自身左右与银幕左右，支持硬切/同向连续/淡出重立三种接缝模式；确定性四阶段门槛校验，仅在画内角色触发口型同步。

### 3. 预算账本、音视频引擎与 Editroom 精剪增强（F16 / F11 / F12）
- **原子预算账本与全表未决防护（F16）**：废除仅查最近 50 条任务的盲区；`BEGIN IMMEDIATE` 原子校验预算与并发重复提交；`UNKNOWN` 状态严禁按已扣费结算或自动重付，完整覆盖 A/B1/B2/C 崩溃恢复矩阵。
- **视频引擎与 Editroom 增强（F11）**：
  - 随包内置 SIL OFL 1.1 中文字体（`resources/fonts/NotoSansCJK-Regular.ttc`），无系统字体依赖；
  - 带时间戳的 ContactSheet 采样图（以 `media_sha256 + 区间 + renderVersion` 为缓存键）；
  - 单镜段缓存与局部接缝转场合成（`0.3–0.8s` `dip_to_black` / `dissolve` + `60–100ms` 音频交叉淡化），修改单镜不失效无关镜头缓存；
  - 混画幅按需 Reframe 焦框平移缩放；分镜/剪辑默认播实际采用裁切区间，独立提供「看原素材」。
- **声音合同与真实人声窗闪避（F12）**：支持三类声音合同（`native_audio` / `silent_tts` / `env_plus_tts`）；基于 `silencedetect` 实测人声窗平滑闪避背景乐；成片 AAC 解码复测 `-16±1 LUFS` / `≤-1.0 dBTP`，超限时纯音轨有界重修 + `-c:v copy` 零重编视频，纯静音单列不适用。

### 4. 外采溯源、质检、多集交付与标准精剪包（F13 / F14 / F17 / F18 / 第五页）
- **外采包强溯源（F13）**：`pack-manifest.json` 绑定项目/分集/镜头 ID 与方案哈希，重排后的旧编号或同名跨项目文件强制进入待人工核对。
- **确定性内容质检与技术质检双门槛（F14）**：正式交付需同时通过内容审核与技术检查且快照一致。
- **第五页「交付」（按需开放）**：仅在作品含两集及以上时展示；提供 SQLite 持久化多集队列、SHA-256 断点续跑（已验分集零重渲）、按序合片、问题原位往返跳转；顶栏不再放置与剪辑页竞争的常驻大号导出按钮。
- **标准精剪素材包（F18）**：输出可重新链接视频素材、4 路独立 48kHz WAV 分轨、SRT 字幕、有理帧率 EDL/JSON、`TIMEBASE.md`、`CHECKSUMS.sha256`、`LICENSES.md`，并校验零密钥/凭据泄漏。
- **增效与纯文本技能模板（F17）**：支持 2×2/3×3 同场宫格与三视图候选、诚实双档路由与 ≤24KB 纯文本 `SKILL.md` 注册表（拦截脚本、凭据提取与绕过计费，支持一键恢复默认）。
- **供应商官方参数预检契约（M01–M04）**：Seedance `content[].role` 互斥与 `ratio: "adaptive"`、Gemini Omni 1.2 Flash 严边界零请求拦截（区分 Flow 网页与 Cloud Vertex Veo）、Kling 与 MiniMax H3 提交/查单/`ffprobe` 校验与 7 天保留期提示（未实测账号默认关闭）。
