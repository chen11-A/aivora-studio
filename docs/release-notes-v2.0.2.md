# AIVORA Studio v2.0.2 发布说明

基于 `v2.0.0` 稳定基线，正式合入并验证**视频镜头连戏、首尾帧/多模态参考、运镜/特效模板、无缝接缝转场与 J/L-Cut 音画错峰导出**全链路，并修复了 FFmpeg 8.1 环境下 J/L-Cut 音轨与 BGM 混音的边界问题。

## 本次新增与升级

### 1. 视频连戏、运镜与特效生成模式
- **三种视频生成模式**：分镜页支持在「首帧图生」「首尾帧桥接」「多参考图+视频」之间按镜头切换，确认生成弹窗如实展示将下发的模式、尾帧、参考视频与原生音画状态。
- **一键抽取上一镜真实尾帧**：新增 FFmpeg 像素级等比裁切尾帧抽取，可直接从上一镜实际视频截取对齐当前工程画幅的最后一帧作为本镜首帧，消除接缝比例跳变。
- **主流视频协议真打通**：
  - **即梦 Seedance 2.0 / 2.5**：完整支持 `first_frame` + `last_frame`（自动 `ratio: "adaptive"`）、`multimodal_ref`（多张 `reference_image` + `reference_video` 复刻运镜与特效节奏，严格遵守官方互斥校验）及 `generate_audio` 原生音画同出；
  - **可灵 Kling**：支持 `image_tail` 首尾帧闭环；
  - **Google Gemini**：支持多主体参考图与时长透传。
- **导演与 VFX 快捷模板**：镜头时长放宽至 30s（预设 `3s / 5s / 8s / 12s / 15s`），内置「12s 三镜时间戳」与「VFX 物理联动（光色反打 / 气浪力学 / 镜头震动 / Audio 行）」结构化模板；场景资产定妆自动增强空间多角度一致性提示。

### 2. 无缝拼接导出与音画错峰
- **剪辑页接缝控制**：右侧检查器可直接为每一处「本镜 → 下镜」接缝设置 `硬切 / 末帧接 / 叠化 / 淡黑`、转场时长（`0.3–0.8s`）以及 **J/L-Cut 音画错峰（`-0.8s ~ +0.8s`）**。
- **自动接通导出与字幕重对齐**：导出管线自动读取镜头接缝设置，自动修正 `dissolve` 叠化后的字幕与对白时间轴偏移，视频零重编码混入 J/L-Cut 平滑音轨，并为每段音频补加 15ms 抗爆音微淡化；修改接缝设置后自动刷新快照摘要，确保正式交付状态诚实准确。
- **FFmpeg 8.1 稳定与 BGM 联动修复**：J/L-Cut 混音改用定长 `anullsrc` 静音底床 + `amix duration=first`，彻底消除 FFmpeg 8.1.3 多线程调度下 `apad` 偶发截断尾部静音导致的音画时长差；同时修复 J/L-Cut 与 BGM 叠加时未沿用错峰音轨的问题。
- **安全增量迁移**：新增备份优先 SQLite 迁移 `v2.0.0_004_video_continuity_and_seams`，无缝兼容 `v1.9.x` 与 `v2.0.0` 旧工程。
