# AIVORA Studio v2.0.3 发布说明

基于 `v2.0.2` 的稳定性与安全热修版，重点修复连戏素材清理误删与跨厂家能力预检漏洞，建议所有 `v2.0.x` 用户直接覆盖升级（保留全部既有作品、配置与预算账本）。

## 本次修复

1. **防误删已绑定的尾帧图与参考视频（P1）**
   - 「清理未引用素材」与数据库回滚校验现已同步扫描 `shots.end_frame_media_path` 和 `shots.reference_video_path`，避免将用户导入的目标尾帧或运镜参考视频误判为孤儿文件删除。
2. **杜绝不支持协议静默丢素材扣费（P1）**
   - 视频生成预检在发包前严格校验当前协议能力：不支持「运镜/特效参考视频」（目前仅即梦 Seedance 支持）、「多参考图模式」（仅 Seedance / Gemini 支持）或「首尾帧桥接」（仅 Seedance / 可灵 / Gemini 支持）的路由组合将被 0 请求中文拦截，不再静默丢弃参考素材后照常扣费。
3. **辅助素材路径与参数边界收敛**
   - 镜头 `endFrameMediaPath` / `referenceVideoPath` 入库强制限定在工程 `assets/` 目录内，防止非法路径写入，并对模式与接缝参数做边界校验。

## 验证情况
- Windows + Linux 双平台 CI（43 组测试、28 组布局审计、Windows NSIS 安装/覆盖升级/卸载冒烟、Linux `.deb` 中文空格路径冒烟）全部通过。
- 注：云端视频新协议参数（Seedance 多模态参考/首尾帧、Kling 尾帧、Gemini 视频时长/多图）仍建议在首次使用真实付费 Key 时先做单镜短时长抽测。
