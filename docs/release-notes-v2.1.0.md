# AIVORA Studio v2.1.0 发布说明

在 `v2.0.3` 视频连戏与无缝接缝管线基础上，正式上线**漫剧/短剧工业级分段背景音乐、留白静音段、按场次一键自动配乐、时间轴精准同步预览与零版权接缝短音效（SFX）系统**。

## 本次核心升级

### 1. 分集独立 · 按镜头区间分段背景配乐
- **告别「全剧一首歌循环到尾」**：每集拥有独立的分段配乐轨（`Episode.bgmCues`），同时 100% 向下兼容 `v1.9.x / v2.0.x` 旧工程的全局 BGM（并自动获得平滑淡入淡出）。
- **底部配乐轨可直接点选分段**：剪辑页四轨时间轴的「配乐」轨道升级为与镜头精准对齐的可点击彩色乐段块，点选任意段落即可在右侧面板精调。
- **一键「按场自动配乐」**：自动识别本集各场次剧情与台词情绪（平静 / 温暖 / 悲伤 / 悬疑 / 紧张 / 史诗 / 搞笑），从内置 CC0 无版权曲库匹配曲目并去重存入本剧复用音乐库，首场后自动跳过慢前奏切入主旋律。
- **短剧高频必用精细控制**：
  - **从当前镜切段**：任意镜头处一键切出新情绪乐段；
  - **当前镜留白**：一键在反转/金句前抽空音乐制造留白张力；
  - **起播偏移（秒）**：裁掉拖沓前奏，直接从高潮/副歌处进；
  - **独立音量（dB）与淡入/淡出（秒）**：相邻音乐段自动平滑交叉淡化，片尾自然收束绝不硬切；
  - **本剧音乐库多集复用**：内置曲库、AI 配乐（Lyria）与本地拖入的 Suno/Udio 成品自动汇总至下拉列表，全剧各集各段随时复用。

### 2. 剪辑预览与导出 1:1 时间轴精准同步
- 新增 `useBgmPreviewSync` 时间轴同步引擎：拖动播放头或切镜时，预览 BGM 实时按 `起播偏移 + 段内经过秒数` 定位，并实时还原淡入淡出、对白自动压低（`-8 dB`）与留白静音，真正做到「剪辑听感 = 成片导出」。

### 3. 零版权接缝/爆点短音效（SFX）与分轨导出
- **剪辑页接缝音效下拉**：在每处「本镜 → 下镜」接缝新增 **扫风转场（Whoosh）/ 低频重击（Hit）/ 悬念上冲（Riser）/ 清脆铜铃（Chime）** 四类纯 FFmpeg 实时合成的零版权短音效，完美遮盖切镜接缝、抬升反转张力，且在时间轴视频块上直观标注 `⚡` 徽章。
- **与 J/L-Cut、叠化与响度校准全打通**：采用定长 `anullsrc` 底床 + `amix duration=first` 确定性混音架构，视频零重编码保持帧级音画同步，并同步打通精修工程包 `03_sfx.wav` / `04_bgm.wav` 真实干音分轨导出。
- **安全增量迁移与诚实交付校验**：新增备份优先迁移 `v2.1.0_005_segmented_bgm_and_seam_sfx`；修改任意分段配乐或接缝音效均实时刷新 `snapshotDigest`，确保正式交付状态诚实可靠。
