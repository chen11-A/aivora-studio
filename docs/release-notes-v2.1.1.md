# AIVORA Studio v2.1.1 发布说明

在 `v2.1.0` 分段配乐与接缝音效管线基础上，本版本针对真机实测暴露的 3 项硬伤完成定向修复（**严守 `-16 ± 1.0 LUFS` 与 `≤ -1.0 dBTP` 质检标准，不放宽任何门槛**）：

## 本次核心修复

1. **自动音量真峰值过冲修复（不再出现 `+0.30 dBTP` 拦截试片/正片导出）**
   - 将限幅器置于 `aresample=48000` 之后消除 192 kHz → 48 kHz 降采样 sinc 吉布斯振铃，首遍预留 `-2.2 dBFS` 编码余量并对 `loudnorm` 测量参数做合法区间钳位；
   - 升级有界纯音频修复（`-c:v copy`，零视频重编，最多 3 次）：按真峰值过冲动态收紧限幅天花板，并结合闭环割线斜率（Secant-slope）收敛增益，高波峰比内置配乐与削波音频均稳定收敛在 `-16 ± 1.0 LUFS` 且 `≤ -1.0 dBTP`。

2. **声画接缝 J/L-Cut 零断声修复（消除 `-0.4s` 硬切 `0.16s` 静音与 `+0.4s` 片尾 `0.40s` 静音）**
   - 负 L-Cut（如 `-0.4s`）：上一镜音频无缝跨切点延展并以等功率 `qsin` 曲线淡出，下一镜自切点同步 `qsin` 淡入叠化，硬切处无静音空洞；
   - 正 J-Cut（如 `+0.4s`）：下一镜音频提前切入上一镜尾部，并平滑补齐原窗口尾段至 `win.endSec`，彻底消除片尾静音与音画脱节。

3. **画外角色严格不列入出场角色**
   - 离线拆镜、AI 提示词与提案清洗（`sanitizeDirectorProposal`）统一过滤明确不入画、未入画、画外音、门外/电话那头、仅台词或回忆提及的角色，不再将其列入镜头 `characters` / `characterAssetIds`，同时保留其 `speaker` 供配音使用；
   - 修复引号近邻说话人匹配，避免句首在场角色抢占引号前画外说话人。
