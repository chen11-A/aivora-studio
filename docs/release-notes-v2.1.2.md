# AIVORA Studio v2.1.2 发布说明

本版本聚焦**单镜表演单 + Google Flow 外采闭环**：首帧负责交代「长什么样、在哪里」，表演单负责交代「怎么动、何时停、最后停在哪」，帮助用户少写提示词也能导出可拍、可编辑、可复核的视频动作提示词。

## 本次核心新增

1. **分镜页单镜表演单（保留原有「动作精修」入口）**
   - 在分镜页动作精修区新增「表演单」面板：按镜头输入本镜剧本、画面描述、时长、景别、机位、已确认在场角色/场景与相邻镜参考上下文，生成结构化四项（**表演意图 / 开场状态 / 顺序动作节拍 / 必须保持与收镜状态**）；
   - 完整支持行内编辑（逐条增删改节拍、修改必须保持与收镜状态）与独立采纳保存；采纳时**绝不静默修改**景别、机位、时长、台词或已有首帧/参考素材，所有模型建议参数均以「建议条」显示并由用户手动确认应用；
   - 不硬卡字数或拍数，不塞固定眨眼/转头模板，参考图负责外观、文字重点锁住运动中容易漂移的物理与空间关系（固定机位、背景不随脸/身体平移、无台词闭口、局部特征随身体移动不换位）。

2. **Google Flow 一键复制与外采包联动**
   - 分镜页「复制提示词并打开 Flow」与剧集外采包（`提示词总表.md` / `提示词总表.txt`）自动优先编译已就绪的单镜表演单；
   - 未写表演单的镜头平滑沿用原有描述，不强制每镜填写。

3. **诚实的「待复核」机制（不挡导出、绝不静默沿用旧单）**
   - 本镜时长、剧本、画面描述、台词、在场角色、场景或关键参考变更后，保留用户已有编辑并标示「待复核」；
   - 用户可明确选择「确认继续沿用」「重新生成」或「不用表演单，复制原描述」；未复核前，一键复制与外采包导出会自动回退原描述并明确标注待复核，绝不偷偷发出过期表演指令。

4. **最小数据库迁移（备份先行、零副作用）**
   - 通过备份先行迁移 `v2.1.2_006_shot_performance_sheet` 在 `shots` 表新增独立可空列 `performance_sheet_json`，重开工程与 ZIP 归档完整保留，不触发前期分镜/美术门禁拦截，也不修改旧工程既有镜头字段。
