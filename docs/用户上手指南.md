# AIVORA Studio v1.6 用户上手指南

欢迎使用 **AIVORA Studio** —— 专为漫剧与短剧创作者设计的本地优先桌面工作台，现已全面支持 **Windows 10/11 (x64)** 与 **Linux (x64)** 双平台。

## 1. 安装与首次启动

### Windows 10/11（64 位）
1. 双击安装包 `AIVORA-Studio-Setup-1.6.1-win-x64.exe`。
   - 默认装入当前用户目录（`%LOCALAPPDATA%\Programs\AIVORA Studio`），**无需管理员权限**。
   - 若出现 Windows SmartScreen 蓝色提示（因当前未购置商业代码签名证书），点击「更多信息」→「仍要运行」即可。

### Linux（64 位：Ubuntu / Debian / Arch / Fedora 等）
- **Ubuntu / Debian / Mint（推荐 `.deb`）**：
  ```bash
  sudo apt install ./AIVORA-Studio-1.6.1-linux-x64.deb
  ```
- **任意 Linux 发行版（免安装 `.AppImage`）**：
  ```bash
  chmod +x AIVORA-Studio-1.6.1-linux-x64.AppImage
  ./AIVORA-Studio-1.6.1-linux-x64.AppImage
  ```
  - 若在 Ubuntu 24.04+ 运行 `.AppImage` 提示沙箱权限受限，附加 `--no-sandbox` 启动即可。
  - Linux 密钥加密使用系统 Secret Service（`gnome-keyring` / `kwallet`），请确保桌面钥匙串服务已启用。

> 双平台安装包均已**内置经 SHA-256 校验的 FFmpeg 8.1 媒体引擎与 7 首 CC0-1.0 无版权精选配乐**，无需额外配置 Python 或 FFmpeg。首次打开建议先点 **「打开示例《晚照书店》」** 体验完整四步流程。

## 2. 四步完整制作流程

1. **① 剧本**：左侧管理分集，中间沉浸写剧本或粘贴小说；点击右侧 **「生成导演拆镜提案」** 可一键提取角色/场景设定并拆出含**原文出处对照**、**对白回溯与结尾覆盖验收**以及**超 16 镜智能合并（绝不截断结尾）**的清单。采纳提案后撤销快照持久化至本地 SQLite，**重启软件后仍可一键撤销**。
2. **② 角色场景**：建立或查看剧本自动提取的角色、场景、道具卡片；支持**直接拖入本地图片**或点 **「AI 生成候选」**，右侧保留历史候选缩略图自由切换对比，满意后再点 **「设为已确认参考」**（不会在未确认前替换已锁定参考）。
3. **③ 分镜**：
   - 左侧支持 **「批量补齐」**（整集增量批量补配音 / 补首帧 / 补视频，自动跳过已就绪镜头，改台词后自动标为待更新）；
   - 顶栏支持 **「网页外采（Flow/即梦）」**（一键导出提示词包与首帧图、批量回流导入，以及开启 **下载目录自动监听**，一键「复制提示词开 Flow」后新落盘 MP4/PNG 自动浮条提示一键归入当前镜头）；
   - 支持 **`↑/↓` 切镜、`Space` 播放、`1~9` 切版本**，以及直接把本地 `.mp4 / .png / .mp3` 拖进中央画布自动入库。
4. **④ 剪辑与导出**：
   - 支持 **`[ 设为入点 (I)` / `设为出点 (O) ]`** 不改原素材裁切、对白区间背景配乐自动平滑压低 8 dB、**「内置配乐」**（7 首 CC0 无版权纯音乐覆盖平静/温暖/悲伤/悬疑/紧张/史诗/搞笑，即点即听一键选用）、**「AI 配乐」**（调用 Gemini Lyria 3.5 生成持久化待试听候选，确认后再采用），以及 **「自动响度统一（-16 LUFS）」**；
   - 点击 **「导出成片」** 导出前自动检查素材完整度、对白时长溢出与字幕单行过长，导出后自动进行成片质检（黑屏 / 静帧 / 无声 / -16 LUFS 破音），按「第 X 秒 · 镜 Y · 怎么修」提示并支持一键定位镜头。

## 3. 模型与账号配置（模型中心）

点击顶栏 **「模型中心」**，所有 API Key 与 OAuth 会话均经系统安全凭据库加密保存（不可用时严禁明文降级）：

- **Google Gemini 官方全家桶（推荐 · 1 个 Key 全搞定）**：填入 1 个 Google AI Studio API Key，保存后点 **「一键套用」**，即可一次性配齐 **剧本拆镜 + 垫图生图 + 异步视频 + 人物配音 TTS + Lyria 3.5 配乐**，零额外配置。
- **即梦 Seedance 2.0/2.5 & 可灵 Kling 官方视频 API**：原生异步提交 → 轮询 → 下载 → `UNKNOWN` 仅 GET 查单找回。
- **ComfyUI 算力直连**：一套标准接口兼容本地显卡、AutoDL 与 Colab 笔记本（支持一键粘贴 `AIVORA-COMFY::...` 连接码）。
- **网页会员授权 & 任意 OpenAI 兼容厂家**：支持 ChatGPT / Grok 网页登录，以及 DeepSeek / 硅基流动 / OpenRouter 等任意中转站。

## 4. 防丢稿与防重复扣费机制

- **零丢稿**：每次修改自动顺序落盘至作品独立 `project.db`；切集、切换作品或退出前同步刷盘，顶栏点 **「备份」** 可导出 `VACUUM INTO` 完整 ZIP 备份包。
- **防重复扣费**：每次 AI 生成前都会弹出确认摘要并锁定快照；若遇网络中断进入 **「状态未知（UNKNOWN）」**，软件**严禁自动重发**，请点顶栏 **「任务」** 使用 **「凭任务号查单找回（仅 GET 查单）」** 找回已生成的成片。
