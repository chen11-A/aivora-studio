# AIVORA Studio v1.2 用户上手指南

欢迎使用 **AIVORA Studio** —— 专为漫剧与短剧创作者设计的本地优先桌面工作台。

## 1. 安装与首次启动（Windows 10/11 64位）

1. 双击安装包 `AIVORA-Studio-Setup-1.2.1-win-x64.exe`。
   - 默认装入当前用户目录（`%LOCALAPPDATA%\Programs\AIVORA Studio`），**无需管理员权限**。
   - 若出现 Windows SmartScreen 蓝色提示（因当前未购置商业代码签名证书），点击「更多信息」→「仍要运行」即可。
2. 安装包已**内置 FFmpeg 8.1.2 媒体引擎**，无需额外配置 Python、FFmpeg 或任何运行环境。
3. 首次打开会进入「作品首页」，建议先点 **「打开示例《晚照书店》」** 体验完整四步流程，或点 **「新建作品」** 选择 `16:9` 横屏 / `9:16` 竖屏。

## 2. 四步完整制作流程

1. **① 剧本**：左侧管理分集，中间沉浸写剧本或粘贴小说；点击右侧 **「生成导演拆镜提案」** 可一键提取角色/场景设定并拆出含**原文出处对照**与**内容对齐 Diff 标签**（标明「对齐原镜·保留版本」或「新增镜头」）的清单。采纳提案后撤销快照持久化至本地 SQLite，**重启软件后仍可一键撤销**。
2. **② 角色场景**：建立或查看剧本自动提取的角色、场景、道具卡片；支持**直接拖入本地图片**或点 **「AI 生成候选」**，右侧保留最近多张历史候选缩略图可自由切换对比，满意后再点 **「设为已确认参考」**。
3. **③ 分镜**：
   - 左侧支持 **「批量补齐」**（整集增量批量补配音 / 补首帧 / 补视频，自动跳过已就绪镜头，2 路并发且随时可暂停派发）；
   - 右侧支持台词正下方 **直接试听配音（含实测秒数与一键贴合时长）**、前插/上移/下移/删除镜头；
   - 支持 **`↑/↓` 切镜、`Space` 播放、`1~9` 切版本**，以及直接把桌面 `.mp4 / .png / .mp3` 拖进中央画布自动入库。
4. **④ 剪辑与导出**：
   - 播放控制条支持 **`[ 设为入点 (I)` / `设为出点 (O) ]`** 一键打点裁切（不改原素材，预览与导出共用同一时间基准）；
   - 静态图片镜头按所选运镜（`缓推 / 缓拉 / 横摇`）在导出时自动应用平滑动态运镜，对白区间自动平滑压低背景配乐 8 dB，并支持 **「自动响度统一（-16 LUFS）」**；
   - 顶栏提供轻量 **「清理未引用缓存」** 按钮（安全释放孤儿文件，绝不删任何历史版本），点击 **「导出成片」** 即可输出 H.264 + AAC 字幕烧录 MP4 成片。

## 3. 模型与账号配置（模型中心）

点击顶栏 **「模型中心」**，所有 API Key 与 OAuth 会话均经 Windows DPAPI 加密保存（系统安全库不可用时严禁明文降级）：

- **网页会员授权**：支持 **ChatGPT**（PKCE 浏览器登录）与 **Grok (xAI)**（OAuth / Device Code）。
- **可灵 Kling 官方视频 API**：协议选择「可灵 Kling 官方视频 API」，填入 Access Key 与 Secret Key，点「测试连接」验证。
- **任意 OpenAI 兼容厂家**：DeepSeek、硅基流动、OpenRouter 或自建中转站均可自由填入 Base URL、API Key 和模型名。
- **四环节自由混搭**：可在底部为「剧本拆镜 / 生图定妆 / 生成视频 / 人物配音」分别指定不同模型。

## 4. 防丢稿与防重复扣费机制

- **零丢稿**：每次修改自动顺序落盘至作品独立 `project.db`；切集、切换作品或返回首页前同步刷盘，写盘失败会弹窗阻断切换。顶栏点 **「备份」** 可一键导出 `VACUUM INTO` 完整 ZIP 备份包。
- **防重复扣费**：每次 AI 生成前都会弹出确认摘要并锁定本批次配置快照；若遇网络中断进入 **「状态未知（UNKNOWN）」**，软件**严禁自动重发**，请点顶栏 **「任务」** 使用 **「凭任务号查单找回（仅 GET 查单）」** 找回已生成的成片。
- **卸载安全**：卸载软件默认保留你的所有作品目录与工程数据，覆盖安装升级同样无损保留。
